# Name Options

`Hot Pursuit` is the working title because it communicates both heat and chase
without tying the product to a particular operator. A trademark, app-store, and
domain check is still required.

Other balloon-friendly options:

| Name | Pun / angle |
|---|---|
| Hot Pursuit | Burner heat plus the chase operation |
| Up & Aground | A twist on “up and around,” with the ground crew built in |
| Chase the Basket | Direct, friendly, and balloon-specific |
| Air Apparent | “Heir apparent” with airborne position context |
| Basket Case | Memorable comic option; may feel too chaotic for guidance |
| The Plot Thickens | Plotting the track while the flight develops |
| Ground Control | Clear crew role, though broadly used elsewhere |
| Loft & Found | “Lost and found” for keeping balloon and chase together |
| Drift Together | Softer, less comic, and good for crew coordination |
| Inflated Expectations | Strong joke, weaker safety/product signal |

Suggested shortlist: **Hot Pursuit**, **Chase the Basket**, and **Loft & Found**.
