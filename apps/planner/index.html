From setup to retrieve

Start with the flight, not a search box.

The map is the setup surface. Move around it, place an approximate landing area, choose its radius, then share one short private code with the chase crew.

  1. 01

    Set an intention

    Tap the map or reuse a previous area. Search is there when planning needs it.

  2. 02

    Bring the crew in

    Create an account-free flight and share its short code or QR invitation.

  3. 03

    Chase the right target

    Keep the balloon in view and choose guidance to it or to the intended rendezvous.

Built for imperfect information

A coordination aid, not an aviation authority.

Weather, wind, airspace, altitude and landing predictions need a visible source, timestamp, units and limitations. Drivers are routed to road-accessible rendezvous points, never blindly to a coordinate.

  • Account-free operation membership via a short code or QR
  • Offline-first event journal with transport-neutral updates
  • Voice-first driver interaction, subject to physical hardware testing

Closed testing

Built in the open. Proved in the field.

Balloon Crumbs is in active development for controlled testers. It is not an emergency service, certified navigation product or source of authoritative flight information.
